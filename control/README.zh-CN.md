# 控制与互操作研究输出

[English](README.md) | **简体中文**

本目录用于存放 OpenMicroDuck 自行产生并公开的控制、协议、互操作和可复现研究成果。

关于官方 Microduck 控制 / 运行时架构的持续维护中文文档，请参阅：

- [机载运行时架构](../docs/zh-CN/software/runtime-architecture.md)
- [电控、总线、传感器与电源](../docs/zh-CN/hardware/electronics-and-buses.md)

放入本目录的资料必须来自公开来源，或能够独立复现的公开观察。本目录不用于存放私有产品设计或与本公开项目无关的内部工程方案。
