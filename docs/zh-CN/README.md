## 文档规则

1. 官方产品资料与官方源码优先于媒体报道和二手资料。
2. 第三方逆向结果必须明确写成“社区推导”，不能包装成官方规格。
3. 不同来源有冲突时保留冲突记录，不静默选择更方便的数字。
4. 不上传没有以兼容许可证公开的 Microduck 专有机械、电路、PCB、原理图等设计文件。
5. 不公开保密、泄露、私有、与本项目无关的专有或其它未公开工程信息。
