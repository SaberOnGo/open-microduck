# 社区推导 BOM 与紧固件重建

> **不是 Microduck 官方 BOM。** 本文记录第三方根据公开 MJCF/STL/源码可复现推导出的结果，量产硬件可能不同。

主要社区来源：https://github.com/fanhao375/microduck-replica

## 为什么单独放一篇

Pollen Robotics 没有公开生产机械/电子 BOM。独立项目 `microduck-replica` 根据公开仿真网格和官方源码反推装配与采购信息。这些结果很有研究价值，但 OpenMicroDuck 将其与 [公开硬件清单](public-bom.md) 分开，防止“模型推导值”被误认为官方制造数据。

## 模型推导的整机快照

对于该社区项目分析的 upstream 模型快照，其报告大致为：

| 属性 | 社区推导结果 |
|---|---:|
| 模型质量 | ~737.2 g |
| 模型包络 | ~144 × 141 × 264 mm |
| 识别到的 Dynamixel XL330 电机 | 15 |
| 策略控制电机关节 | 14 |
| 额外电机 | 嘴/喙 |

这些数字描述的是该次公开模型快照，不是零售量产机上秤/卡尺实测。产品规格仍以官方 **25 cm 高、14 cm 宽、低于 800 g** 为准。

## 紧固件几何反推

社区项目扫描公开 mesh 中的圆柱孔特征，得到明显以 M2 为主的孔径聚类。

部分公开统计：

| 网格特征 | 报告数量 | 社区解释 |
|---|---:|---|
| ~Ø2.2 mm | 77 | M2 过孔 |
| ~Ø4.4 mm | 28 | 与 M2 紧固件头部/沉孔相关的特征 |
| ~Ø1.6 mm | 20 | 接近 M2 攻丝底孔 |
| ~Ø2.4 mm | 22 | 较松 M2 过孔候选 |
| ~Ø2.0 mm | 12 | 较紧 M2 级孔特征 |
| ~Ø2.7–2.8 mm | 20 | 可能的 M2.5 级过孔 |

该分析在排除舵机/外购件特征后，还估算约 **146 个结构件 M2 级过孔实例**。

### 重要限制

仿真/视觉 mesh 中出现某个孔，并不能证明量产机使用了某一具体螺丝、长度、嵌件、公差或装配工艺。网格可能简化螺纹、隐藏嵌件，也可能来自开发 revision。

该项目根据孔深分布给出了一套偏保守的试装采购估算：

| 物料 | 社区估算 |
|---|---:|
| M2×4 内六角圆柱头 | ~60 |
| M2×6 | ~80 |
| M2×8 | ~40 |
| M2×12 | ~15 |
| M2 螺母 | ~50 |
| M2 热熔嵌件 | ~60 |

这些数字**不是量产 Microduck 实际使用数量**，而是第三方为试装、损耗留余量的采购建议。

## 从公开网格推导的轴承几何

| 模型推导几何 | 说明 |
|---|---|
| 外径 22 mm × 内径 16 mm × 宽 4 mm | 可由公开资产名称/几何直接对应 |
| 外径约 15 mm × 内径约 10 mm × 宽 3 mm | 公开模型中的较小轴承几何 |

仅凭 mesh 无法确定供应商、精度等级、材料、密封形式、额定负载和最终量产数量。

## 可公开识别的电子部件

把可从官方源码交叉确认的内容与社区重建组合，可得到如下研究清单：

| 区域 | 可公开识别项 | 状态 |
|---|---|---|
| 主控 | RK3566；当前源码在 Radxa Zero 3/3W 上 bring-up | 官方产品/源码；开发板 revision 可能变化 |
| 执行器 | Dynamixel XL330 系列；runtime 有 15 个 motor ID | 官方源码 |
| 主控制 IMU | LSM6DSV16X，`imu_to_dxl` v2，ID 200 | 官方源码 |
| 当前摄像头开发路径 | IMX219 / Raspberry Pi Camera v2 | 官方源码，开发路径 |
| ToF 软件支持 | VL53L5CX / VL53L8CX | 官方源码；最终量产料号未冻结 |
| 当前音频开发路径 | TLV320AIC3104 | 官方源码，开发路径 |
| 产品电池 | 可拆 NP-F550，2600 mAh | 官方产品规格 |
| 自制板接口功能 | 可根据 runtime 和模型推断 bus bridge / Pi-HAT 类功能 | 官方公开信息 + 社区重建；没有官方生产原理图/BOM |

## PCB / 模型几何说明

第三方已经对公开仿真模型中的 PCB-like 几何做了尺寸测量，并据此研究当前开发模块之间的装配关系。这些结果适合解释公开模型，但本文不会把它们包装成量产 PCB 工程图。

OpenMicroDuck 不包含任何未公开原理图、PCB 设计文件、Gerber 或专有生产 CAD。

## 如何复现社区分析

`microduck-replica` 不仅提供结论，也提供脚本：从官方 upstream 获取公开 RL 资产、应用 MJCF transform、生成装配/爆炸视图、导出变换后的 STL，并扫描孔几何。

如果需要精确模型数据，建议固定 upstream commit 后重新运行脚本，而不是把某次分析结果当成永久规格。

## 许可证与来源

该社区仓库对脚本与衍生 CAD/图片使用不同许可证；其 CAD/装配衍生作品继续受上游 3D 资产的非商业/share-alike 条款影响。因此 OpenMicroDuck 当前只总结技术结论并链接来源，不直接搬运其 CAD/图片。
