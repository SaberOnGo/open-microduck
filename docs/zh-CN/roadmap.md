# OpenMicroDuck 公开文档路线图

[English](../en/roadmap.md) | **简体中文**

本路线图只跟踪 **OpenMicroDuck 公开研究与文档项目**，不是任何商业产品研发计划，也不描述私有硬件项目。

## 当前优先事项

1. 持续维护有公开来源支撑的 Microduck 硬件清单，不把它误写成“官方完整 BOM”。
2. 只要官方公开证据足够，就直接写出具体器件型号，而不是只写模糊类别。
3. 持续区分官方产品规格、当前官方源码中的开发硬件，以及仿真资产中的模型信息。
4. 整理公开机械/运动学结构，并明确“仿真模型 ≠ 量产工程图”的边界。
5. 维护已审查的逆向分析、仿真器、RL port 和互操作项目索引。
6. 对版本敏感的数据尽量引用到具体 commit / file path。
7. 在有量产实机公开测量后，增加可复现实测数据。
8. 保持英文与简体中文文档按主题并列维护。
9. 持续明确上游软件、3D 资产和社区衍生内容的来源与许可证边界。

## 文档范围

- 产品 / 公开规格；
- 硬件清单与 BOM 状态；
- 机械结构与运动学；
- 电控、总线、传感器与电源；
- 运行时 / 软件架构；
- 仿真、强化学习与 sim-to-real；
- 社区逆向与工具生态；
- 证据、来源与许可证。

## 贡献原则

新增内容应来自公开可追溯来源，并适合放在公开仓库中。私有、保密、泄露、与本项目无关的专有资料，或其它未公开工程信息，不属于 OpenMicroDuck 的公开内容范围。

详见[研究规范](research-guidelines.md)。
