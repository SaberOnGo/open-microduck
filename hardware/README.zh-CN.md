# 硬件研究输出

[English](README.md) | **简体中文**

本目录用于存放 **OpenMicroDuck 自行产生并公开的研究输出**，例如独立绘制的示意图、公开测量数据、脚本和可复现分析。

关于 Microduck 本体硬件的持续维护文档，请进入中文文档树：

- [Onshape 交互式总装基线](../docs/zh-CN/hardware/onshape-interactive-assembly.md)
- [公开硬件清单与 BOM 状态](../docs/zh-CN/hardware/public-bom.md)
- [社区推导 BOM、紧固件、轴承与装配重建](../docs/zh-CN/hardware/community-bom-reconstruction.md)
- [机械结构与运动学](../docs/zh-CN/hardware/mechanical-structure.md)
- [电控、总线、传感器与电源](../docs/zh-CN/hardware/electronics-and-buses.md)

不得在本目录放入泄露、保密、私有、与本公开项目无关的专有资料或非法获得的材料；不得上传未公开且没有兼容授权的第三方 Microduck CAD、PCB、原理图、固件或制造文件。

公开上游资料和社区推导资料必须保留来源/证据标记。详见[研究规范](../docs/zh-CN/research-guidelines.md)。
