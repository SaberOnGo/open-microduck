# 强化学习研究输出

[English](README.md) | **简体中文**

本目录用于存放 OpenMicroDuck 自行产生并公开的强化学习实验、评估结果和可复现工具。

关于官方 Microduck RL 栈的持续维护中文文档，请参阅：

- [仿真与强化学习](../docs/zh-CN/simulation/model-and-rl.md)
- [已审查的社区仿真 / RL 项目](../docs/zh-CN/ecosystem/reverse-engineering-projects.md)

公开实验产物应在适用时记录：仿真器/模型 revision、源码 commit、observation/action 定义、reward 配置、randomization 设置和评估方法。

不得把私有项目或与本公开项目无关的工程/训练数据加入本公开仓库。
