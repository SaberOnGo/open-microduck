# 仿真研究输出

[English](README.md) | **简体中文**

本目录用于存放 OpenMicroDuck 自行产生并公开的仿真实验、验证数据和工具。

关于官方 Microduck 仿真 / RL 栈的持续维护中文文档，请参阅：

- [仿真与强化学习](../docs/zh-CN/simulation/model-and-rl.md)
- [机械结构与运动学](../docs/zh-CN/hardware/mechanical-structure.md)

本目录新增的模型参数，应注明其来源类型：官方源码、公开实测、公开观察、社区重建、推导，或明确的仿真假设。

不得把私有项目或与本公开项目无关的工程数据混入公开 Microduck 仿真数据集。
